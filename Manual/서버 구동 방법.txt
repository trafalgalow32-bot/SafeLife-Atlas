[개요/설계]아키텍처 구성: 독립된 두 개의 개발 서버를 동시에 구동합니다.
백엔드 (API 서버): Python 가상환경(.venv) 활성화 $\rightarrow$ Uvicorn 기반 구동 ([http://127.0.0.1:8000](http://127.0.0.1:8000))
프론트엔드 (UI 클라이언트): Node.js 런타임 $\rightarrow$ Vite HMR 개발 서버 구동 (http://localhost:5173)
사전 권장사항: VS Code에서 터미널 창을 2개 분할(Split)하여 각각 백엔드와 프론트엔드 프로세스를 할당합니다.

[서버 실행 명령어]1. 백엔드 (FastAPI) 구동Git Bash 터미널 사용 시:

# 1. 루트 경로로 이동
cd /c/KHK/SafeLife-Atlas

# 2. 파이썬 가상환경 활성화
source .venv/Scripts/activate

# 3. backend 디렉터리로 이동 후 실행
cd backend
python -m uvicorn app.main:app --reload

Windows PowerShell 사용 시:
# 1. 루트 경로로 이동
cd C:\KHK\SafeLife-Atlas

# 2. 파이썬 가상환경 활성화
.\.venv\Scripts\Activate.ps1

# 3. backend 디렉터리로 이동 후 실행
cd backend
python -m uvicorn app.main:app --reload

확인 URL:

Swagger API 문서: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

코어 데이터 엔드포인트: [http://127.0.0.1:8000/api/v1/domains/voice-phishing/graph](http://127.0.0.1:8000/api/v1/domains/voice-phishing/graph)

2. 프론트엔드 (Vite React) 구동
새 터미널(Git Bash 또는 PowerShell)을 열고 실행합니다:

# 1. frontend 디렉터리로 이동
cd /c/KHK/SafeLife-Atlas/frontend

# 2. Vite 개발 서버 구동
npm run dev

확인 URL:

애플리케이션 화면: http://localhost:5173

[설명 및 주의점/리스크]
실행 순서:프론트엔드가 마운트될 때 백엔드 API에 즉시 요청을 전송하므로, 백엔드 서버를 먼저 실행한 후 프론트엔드를 구동해야 초기화 통신 에러를 방지할 수 있습니다.   
백엔드 실행 경로 종속성:Uvicorn 실행 시 반드시 cd backend로 이동한 상태에서 app.main:app을 호출해야 합니다. 루트 경로에서 직접 실행하면 ModuleNotFoundError: No module named 'app'이 발생합니다.
서버 종료:실행 중인 터미널에서 각각 Ctrl + C를 누르면 서버 프로세스가 정상 종료됩니다.
