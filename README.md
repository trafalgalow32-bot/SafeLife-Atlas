# SafeLife-Atlas

> 과학기술 기반 **사회문제해결 R&D의 성과를 데이터 관점에서 가시화·분석**하는 마중물(portfolio) 프로젝트

`React 19 + React Flow` · `Python + FastAPI` · `Accessibility First`

---

## 📌 프로젝트 개요

복잡한 사회문제를 **세부문제 단위의 인과 구조**로 분해하고, 데이터 관점에서 탐색하는 인사이트 도구입니다.
제시 자료는 KISTEP(한국과학기술기획평가원)의 공공 발간물을 **공공누리 이용약관에 따라 출처를 표기하여** 활용합니다.

**왜 이 프로젝트인가 (진정성):**
흔한 CRUD 게시판 대신, 재직 시절 직접 기여한 범부처 사회문제해결 R&D 보고서(13개 사회문제 영역 · STEEP 분류)를 1차 원천으로 삼습니다. 누구도 복제할 수 없는 자료가 이 포트폴리오의 차별점입니다.

## 🎯 v1 대표 슬라이스 — 보이스피싱 (전기통신금융사기)

현재 v1은 **보이스피싱** 도메인 하나를 백엔드→프론트까지 관통한 **수직 슬라이스**입니다.
넓게 파다 만 여러 개보다, 하나를 끝까지 뚫은 결과물을 우선합니다.

- 세부문제 **22개**(발생 원인 16 / 파급 영향 6)를 **원인 → 영향 인과 구조**로 모델링
- 각 노드에 **시급성 점수 · 과기해결 기대 점수 · 대응 사분면**(기술주도 / 제도주도 / 복합 / 장기) 부여
- 2023년 R&D 우수성과·동향브리프를 노드 상세 하단 **경량 레퍼런스 칩**으로 연결

### ♿ 간판 기능 — 접근 가능한 그래프 (Accessibility First)

이 프로젝트의 **명분은 접근성**입니다. (사전 이용자 설문에서 '글자 작음·텍스트 나열·느림·복잡'이 공공 정보서비스의 핵심 불만으로 지적됨)

그래프 시각화는 스크린리더에 거의 읽히지 않습니다. 그래서 **같은 데이터를 두 개의 뷰로 렌더**합니다.

| 뷰 | 내용 |
|---|---|
| 노드 그래프 뷰 | React Flow 기반 원인–영향 인과 구조 탐색 |
| 접근성 목록 뷰 | 동일 JSON을 의미론적 계층 목록(`<details>`/`<summary>`)으로 재구성 · 키보드(Tab/Enter)·스크린리더 완주 지원 |

> "정부가 시민에게 실패한 접근성을, 그래프에서까지 해결한다."

**목표 지표 (WCAG 2.1 AA):** Lighthouse 접근성 ≥ 95 · 키보드 100% 도달 · 명도 대비 4.5:1
> ⚠️ Lighthouse 자동검사는 접근성 이슈의 약 30%만 잡습니다. 키보드 완주·스크린리더 실사용 **수동 검증**을 진짜 증거로 삼습니다. *(측정 결과·데모 GIF는 배포 후 첨부 예정)*

### 🔎 분석 엔드포인트

정적 데이터 서빙을 넘어, `/api/v1/domains/{id}/analytics`에서 도메인 집계를 제공합니다:
사분면 분포, 시급성·과기기대 평균, 그리고 **시급성 대비 과기해결 갭**(체감 문제는 크나 기술 대안이 취약한 → 제도 대응 우선 노드) Top 3.

## 🛠 Tech Stack

| 영역 | 기술 |
|---|---|
| Frontend | React 19 · React Flow(@xyflow/react) · TypeScript · Vite |
| Backend | Python · FastAPI (Pydantic, 자동 Swagger) |

## 🚀 로컬 실행

백엔드와 프론트엔드를 각각 구동합니다. **백엔드를 먼저** 띄워야 프론트 초기 통신 에러를 방지합니다.

```bash
# 1) 백엔드 (FastAPI)
cd SafeLife-Atlas
source .venv/Scripts/activate          # PowerShell: .\.venv\Scripts\Activate.ps1
cd backend
python -m uvicorn app.main:app --reload
# → API 문서: http://127.0.0.1:8000/docs

# 2) 프론트엔드 (Vite) — 새 터미널
cd SafeLife-Atlas/frontend
npm install
npm run dev
# → 화면: http://localhost:5173
```

**현재 상태:** 로컬 구동 단계 (배포는 진행 예정). API 주소는 환경변수(`VITE_API_BASE_URL`)로 분리되어 있어, 백엔드 호스팅 후 코드 수정 없이 배포에 대응합니다.
